# Each Participant gets a private Board

A Trial Cycle tests every Participant on the same problem, and the point is to see how each person breaks down and executes work, not only the final result. A shared trial board let Participants copy each other and hid individual approach. So each Participant works on their own private Board, seeded with copies of the Founder's Challenges, which they then own entirely (split, edit, add, move). Only that Participant and the Startup's Founders can see a Board.

Communication follows the same isolation: a private Thread per Participant with the Founders, plus one-way Announcements to everyone — not a group channel.

## Consequences

- Pulses on a Board carry the owning Participant; Challenges are separate template records, copied at start and again when added mid-trial. Editing a Challenge never changes copies.
- Boards use todo → in progress → done with no review step; the Participant's Submission (summary + Proof Links) is what the Founder judges. A Verdict, or the end date, locks the Board and Submission.
