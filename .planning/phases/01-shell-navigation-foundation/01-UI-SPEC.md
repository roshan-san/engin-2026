## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge padding |
| sm | 8px | Compact element spacing, sidebar item internal gap |
| md | 16px | Default element spacing, sheet/card padding |
| lg | 24px | Section padding (sheet header, stub screen padding) |
| xl | 32px | Layout gaps, standard control/row height (`h-8`) — D-05's "~32px rows and controls" |
| 2xl | 48px | Major section breaks (between sidebar's personal/Startup/Discover groups) |
| 3xl | 64px | Page-level spacing (rare in this phase — mostly stub screens) |

Exceptions:
- **44px (`h-11`) touch targets on mobile** — bottom tab bar items, mobile top bar's avatar and
  search tap targets, any icon-only button below the `md:` breakpoint. Per D-05.
- **6px (`--radius`)** is a corner-radius token, not a spacing token — see Color section for the
  full token list; called out here only so it isn't mistaken for a missed spacing value.

## Typography

Geist only (D-02), two weights, tabular numbers for keycaps/counts (`font-variant-numeric:
tabular-nums` on badge/count/keycap elements — no mono font exists in this phase).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 400 (regular) | 1.4 — sidebar section labels, badge text, timestamps |
| Body | 14px | 400 (regular) | 1.5 — default UI text, palette rows, sheet body, stub-screen `EmptyState` description |
| Heading | 16px | 600 (semibold) | 1.2 — sheet titles (`?` sheet, Startup sheet, account sheet), `EmptyState` title, sidebar Focused-Startup name |
| Display | 20px | 600 (semibold) | 1.2 — page-level title in the mobile top bar and any stub screen's top-of-page heading |

Only these 4 sizes and 2 weights are declared for this phase. `13px` from D-05's "13–14px" range
is intentionally not used as a fourth size — 14px covers the body role and keeps the scale to 4
sizes; drop to 13px only if a later phase's density audit calls for it.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Create Startup" — the switcher's empty state, sidebar Focused-Startup section, and mobile Startup sheet all use this exact label (glossary term, matches SHELL-02's "Create a Startup" wording in the switcher) |
| Empty state heading | Per-screen — see "Stub Screen Copy" table below |
| Empty state body | Per-screen — see "Stub Screen Copy" table below |
| Error state | Heading "Something went wrong", body: the caught error's message via `toErrorMessage(error, "Something went wrong")` — reuses `GlobalError.tsx`'s existing pattern verbatim; no new error copy is introduced by this phase |
| Destructive confirmation | None in this phase. Every Phase 1 screen is either shell chrome (no destructive actions) or a bare stub (no interactive content at all) — Leave Startup / Cancel Trial Cycle / etc. belong to Phase 3/4 |

### Stub Screen Copy (D-10 discretion — title + `EmptyState`, reusing `EmptyState.tsx`)

Every route a later phase rebuilds renders `<EmptyState title=… description=… />` with no
action button (the primary CTA above only appears where a Startup is genuinely missing, not on
every stub). Screen-level `<h1>` title uses the Display role (20px/600); the `EmptyState`
component's own title uses its existing `font-medium` styling (Heading role, 16px/600).

| Route | Page `<h1>` | `EmptyState` title | `EmptyState` description |
|-------|-------------|---------------------|---------------------------|
| `/my-pulses` | My Pulses | No Pulses yet | Pulses assigned to you across every Startup will show up here. |
| `/inbox` | Inbox | Nothing here yet | Notifications, Offers and Invites will show up here. |
| `/threads` | Threads | No Threads yet | Your Trial Cycle Threads with Founders will show up here. |
| `/s/$slug/cycles` | Cycles | No Cycles yet | This Startup's Cycles will show up here. |
| `/s/$slug/cycles/$cycleId` | Cycle | Board coming soon | This Cycle's Pulses will show up here. |
| `/s/$slug/hiring` | Hiring | No open Roles yet | Roles, Trial Cycles and Applicants will show up here. |
| `/s/$slug/hiring/trials/$trialCycleId` | Trial Cycle | Board coming soon | This Trial Cycle's Challenges and Participants will show up here. |
| `/s/$slug/team` | Team | No Members yet | This Startup's Members and pending Invites will show up here. |
| `/s/$slug/pitch` | Pitch | Pitch editor coming soon | Edit this Startup's Pitch sections here. |
| `/s/$slug/activity` | Activity | No activity yet | This Startup's events will show up here. |
| `/s/$slug/settings` | Settings | Billing coming soon | This Startup's Plan and usage will show up here. |
| Profile edit | Edit profile | Profile editor coming soon | Edit your profile details here. |

Startup-scoped stub routes (`/s/$slug/...`) with **no Focused Startup at all** instead render the
switcher's own empty state ("Create Startup") — they never reach their own `EmptyState`, since
`/s/$slug/...` requires a resolved Startup by definition (SHELL-02).
