## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored notification -> browser navigation | The href string is stored at write time and followed by the client later |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06 | Tampering | href builders in convex/lib/links.ts | low | mitigate | Hrefs are assembled only from server-generated values (`startup.slug` from `uniqueSlug`, document ids). No user-typed text reaches a URL, so there is no open redirect or path injection |
| T-01-07 | Information Disclosure | slug inside a notification href | low | accept | Notifications go only to Founders, Members, Participants or Applicants of that Startup's Trial Cycle, who already know the Startup |
| T-01-08 | Denial of Service | extra `ctx.db.get(startupId)` per notification | low | accept | One point read per notify call, inside mutations that already read the Startup's documents; bounded |
| T-01-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no packages |
</threat_model>
